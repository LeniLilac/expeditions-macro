# Expeditions Macro v1.3.0-beta.50

This beta improves Placement Setup fallback authoring, makes newly added actions follow the common after-start workflow, adds saved-plan deletion, hardens Bounty Challenge setup reuse, and supports both reviewed Infinite wave-counter layouts. It is published as a silent prerelease and does not send a Discord release announcement.

## Highlights

- Removing the final user-authored action from a fallback-capable exact Step Mode setup now restores its shared category setup. The required Start Game row no longer keeps an otherwise empty override active.
- Newly added Match Steps and placement-map points start at the bottom below Start Game. Existing saved order is preserved, and users can still explicitly move an action above Start Game.
- Macro Plan now includes a confirmed Delete action for saved plans, with pending autosave flushed before deletion and deterministic next-plan selection.
- Legacy placement rows on the canonical client edge, including the default `(0,0)` coordinate, are skipped before their unit-selection key or coordinate input. New edge coordinates are rejected during authoring.
- Regular Challenge work selected by Bounty mode reuses the matching Story Infinite Placement Setup through a Challenge-scoped runtime copy; the saved setup is not changed.
- Infinite Bounty wave recognition covers the retained and no-voice top-bar locations. It scores digits only at the uniquely owned dark/blue Wave pill and ignores matches unless the independent gameplay HUD is also present.

## Safety boundaries

- Category setups and routes assigned to Recording Mode remain configured; only an otherwise empty exact Step Mode override falls back.
- Plan deletion cannot target an unsaved plan and cannot run while a Macro operation owns the app.
- Unsafe legacy rows remain visible and editable; they are skipped individually so later valid placement work can continue.
- Expanding the wave search does not make digits sufficient ownership evidence: exactly one local dark pill plus blue Wave badge must own the counter, the Stage hotbar plus Unit Manager and Stage Info controls must own the frame, and the existing temporal wave sequence remains mandatory.
