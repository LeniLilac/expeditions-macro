# Expeditions Macro v1.3.0-beta.41

This silent prerelease adds interval-based resource Utilities and replaces split placement phases with one explicit, editable Match Steps timeline. It does not send a Discord release announcement.

## Highlights

- Macro Plan can schedule Gold Mine, Resource Drill, or combined refuel Utilities at a configurable interval without blocking other eligible tasks.
- Placement Setup now uses one ordered timeline around a required Start Game action, with Place, Reconfigure, Delay, and Upgrade actions plus stable IDs for repeated units.
- Advanced mode exposes bounded Step Mode timings and Recording Mode prestart behavior while keeping tested defaults in control when it is off.
- Gold Mine and Resource Drill detection now covers both fuel-present and missing-fuel states, revalidates every live refuel action, and fails closed through bounded cleanup.
- Slow-device selected-unit waits, Challenge dialog partitioning, Expedition retries, Test playback, and per-match unit state ownership are hardened at their real runtime boundaries.
- Placement and Macro Plan authoring are more responsive: action dialogs are true modals, steps grow with the page, markers avoid collisions in both axes, and drag targets follow the nearest insertion boundary.
