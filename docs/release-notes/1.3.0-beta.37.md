# Expeditions Macro v1.3.0-beta.37

This silent prerelease simplifies ordinary placement playback, fixes reconnect-toggle persistence, and makes Priority 1 the default Auto Upgrade choice for newly authored steps. It does not send a Discord release announcement.

## Highlights

- Step Mode holds the configured Quick Placement key while repeating one unit-slot tap and one direct coordinate click. The selected-unit panel is the only placement proof, and the transaction remains capped at eight attempts.
- Placement no longer presses Cancel Placement, runs a slot-normalization preamble, image-detects the cyan Quick Placement title, double-clicks each attempt, or uses a timed mouse approach.
- Quick Placement is released before targeting and Auto Upgrade input and on every cancellation or failure path.
- Newly authored map points and captured placement steps default to Auto Upgrade Priority 1. Existing saved and legacy defaults remain compatible.
- Both private-server restart checkboxes persist immediately, so page navigation cannot restore the previous value.
