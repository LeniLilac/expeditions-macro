# Expeditions Macro v1.3.0-beta.27

This silent prerelease keeps startup settings normalization operation-scoped, adds keyboard placement-step deletion, and protects current Story and Raid Victory layouts. It does not send a Discord release announcement.

## Highlights

- UI Scale and required game settings are checked once when a Macro plan starts. A later Lobby return or private-server restart resumes the saved task without changing settings again.
- If that initial startup check itself cannot finish, recoverable process relaunch may retry it until the operation has been prepared successfully.
- Pressing `Delete` removes the selected Placement Setup step in both Fast no-align and legacy placement editors, except while editing a text field.
- Current Story and Raid Victory panels with **Next Stage** continue to resolve their live **Repeat Stage** action instead of advancing.
