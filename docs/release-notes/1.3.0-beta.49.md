# Expeditions Macro v1.3.0-beta.49

This beta makes Bounty Board recognition independent of the changing Event sidebar and adds an annotation workflow to the source-only Detector Viewer. It is published as a silent prerelease and does not send a Discord release announcement.

## Highlights

- Fixes Bounty mode reaching a visibly loaded Bounty Board but never rerolling because the selected Event sidebar card rendered differently.
- Owns the Bounty Board through the independently aligned Back and Calendar action rail plus the bounded Bounty Board header, without depending on card artwork, the Event sidebar, or a one-pixel decorative line.
- Adds a bounded header glyph recognizer as a fallback when normal gold-title evidence changes. The fallback cannot authorize the Board without the live Back and Calendar rail.
- Lets Detector Viewer load every supported repository dataset image, automatically choose its associated detector, and keep its frame picker correctly themed.
- Adds autosaved per-fixture annotations for expected results, implementation notes, and multiple labeled canonical detection regions.

## Detector safety boundaries

- The Board header and Back/Calendar rail are both required before the detector owns the screen.
- Header text recognition is restricted to the annotated crop and is corroborative only; text alone never authorizes input.
- Mutable bounty cards, rewards, sidebar artwork, page-body brightness, and exact one-pixel lines do not own Board state.
- Annotation files guide implementation and review but never change runtime detector decisions.
