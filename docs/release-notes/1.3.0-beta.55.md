# Expeditions Macro v1.3.0-beta.55

This beta adds field-verified support for a third Roblox top-bar layout during Infinite Bounty wave monitoring. It is published as a silent prerelease and does not send a Discord release announcement.

## Highlights

- Recognizes the compact top-bar Wave counter at its observed `(386,28)` client-relative origin.
- Keeps the retained and no-voice Wave layouts at `(389,48)` and `(421,28)` unchanged.
- Requires the local Wave badge and counter-pill structure plus the independent gameplay hotbar, Unit Manager, and Stage Info controls before a number can advance Bounty exit evidence.
- Preserves bounded one-pixel raster tolerance and rejects frames where two supported layouts appear owned at once.

## Validation

- Replayed all 683 supplied field frames; 623 of 629 gameplay-owned frames were recognized with no temporal wave regressions, including stable wave 17, 32, 47, and 62 readings.
- Added focused coverage for every embedded 0-through-100 template at all three layouts, raster phase variation, inactive anchors, ambiguous layouts, and missing gameplay ownership.
- Passed 1,591 non-golden application tests and 120 golden-image and cross-state detector tests.
- Passed 6 Deep Debug Viewer tests, 15 Detector Viewer tests, and all 90 dark/light main-app UI states.
- Passed locked restore, zero-warning Release build, repository policy, formatting, diff hygiene, packaging, and privacy checks.
