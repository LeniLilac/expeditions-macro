# Expeditions Macro v1.3.0-beta.61

This beta fixes the repeated Roblox recovery loop that could follow Bounty claims. It is published as a silent prerelease and does not send a Discord release announcement.

## Highlights

- Keeps the real right-view Reroll action when a neighboring gold pin produces an equal left-view column match.
- Lets the just-claimed Bounty slot settle as dimmed while preserving any remaining usable card.
- Prevents the Bounty reconciliation retry from consuming all ten automatic Roblox restarts and stopping the Macro Plan.

## Safety boundaries

- The detector still accepts only bounded yellow Reroll components on one of the two reviewed card-column families.
- The tie-break changes only equal-card-count interpretations and selects the family with the lower total column distance; it does not broaden component colors, geometry, or search regions.
- Bounty actions still require two stable fresh Board observations before input.

## Validation

- Reproduced the supplied beta.60 failure on its exact privacy-reviewed Bounty Board frame: the previous detector returned the gold pin at x=680, while this release returns the live Reroll at x=761 and settles claimed slot 4 as dimmed.
- Passed all 1,758 application tests, including the complete detector cross-state corpus.
- Passed 6 Deep Debug Viewer tests and 15 Detector Viewer tests.
- Passed locked restore, zero-warning Release build, repository policy, and diff hygiene. Packaging, checksum verification, and packaged-app smoke checks are performed by release preflight and the tag workflow.
