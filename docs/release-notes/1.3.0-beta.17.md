# Expeditions Macro v1.3.0-beta.17

This silent beta improves saved-team loading, current Raid navigation, and dense camera setup reliability. It does not send a Discord release announcement.

## Saved teams

- Unit Teams scrollbar detection now anchors the real thumb to the detected panel Close control instead of choosing similarly sized gray scenery.
- Team 7 and Team 8 alignment over-drags past the lower track so Roblox clamps the thumb at its physical bottom limit.
- Lower-team loading continues to verify a fully visible detected action before clicking.

## Raid navigation

- Current Spirit City detail panels are recognized with either Roblox font setting.
- Detail recognition uses the shared red header, top accent edge, dark panel body, and live **Select Stage** action instead of requiring the decorative Close circle to remain visually isolated.
- Act selection proceeds through the detected live panel geometry.

## Camera setup

- Dense setup discards a repeated revolution only when distributed fingerprint and registered-structure evidence independently prove that the first loop seam was skipped.
- Atlas fingerprint isolation now scales with atlas density, preventing adjacent yaw samples from being treated as remote duplicates.
- Setup restoration constrains each post-pulse lookup to the physically reachable yaw neighborhood and adapts its remaining correction near the goal.
- A fine-mouse correction that verifies the full-resolution goal beside the circular atlas seam now completes the return instead of oscillating between one left and one right arrow pulse.

## Validation

- All 637 application and detector tests pass, including the complete cross-state corpus and focused camera, saved-team, and Raid regressions.
- All 5 Deep Debug Viewer tests pass.
- Repository policy, scoped formatting, diff checks, secret/path review, and a warning-free Release build pass.
