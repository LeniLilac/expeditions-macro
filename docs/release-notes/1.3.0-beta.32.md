# Expeditions Macro v1.3.0-beta.32

This silent prerelease makes authoring safer through complete autosave, replaces the remaining device-dependent Roblox accessibility navigation, and closes several field-reported startup and navigation failures. It does not send a Discord release announcement.

## Highlights

- **Macro Plan and Placement Setup now save automatically.** Every committed edit enters a serialized autosave queue with visible status. Starting, testing, sharing, switching, navigating away, and shutting down flush outstanding work. The lifecycle also protects rapid renames, writes queued during another save, retryable failures, and in-flight placement writes.
- **Placement steps are more expressive.** Existing steps can move between Before Start and After Start without losing their unit, coordinate, delay, targeting, or upgrade settings. Auto Upgrade is now Off or Priority 1 through Priority 6, with playback sending that key the exact selected number of times.
- **Optional game keybindings can be cleared.** A compact X appears directly beside each configured Anime Expeditions binding. The macro hotkey remains required, and Escape continues to cancel capture rather than silently clearing a value.
- **Settings and Lobby return are vision-guided.** The macro detects and clicks the fixed opaque gear and door glyphs at either supported top-bar offset. It ignores microphone/headset artwork, does not scale those coordinates with game UI Scale, closes Settings through the same gear, and never uses the red panel Close button or accessibility navigation.
- **Startup UI Scale correction is reachable after a restart.** A stable near-threshold Lobby can authorize only the configured startup preflight. UI Scale is corrected first, then strict Lobby proof is still required before any task input.
- **Event entry handles different account defaults.** The selected colored Event tab proves whether Villain Invasion is active. If another Event is selected, the macro clicks the verified Villain Invasion row once and separately confirms its home page.
- **Play navigation supports accounts with locked modes.** Story/Raid handoff accepts consecutive bundled Play-selector evidence when the specialized detector returns no Stage state because a mode tile is locked and dim. A pending observation waits instead of pressing the Play key again, and recognized Stage states always take precedence.
- **Pinned Roblox follows actual coverage.** Focusing a non-overlapping app or another monitor keeps the Dashboard view pinned. Positive-area overlap or a macro-owned dialog suspends it without minimizing, while leaving the page, scrolling the live view away, or minimizing the macro retains the intended automatic Roblox minimize behavior.
- **Manual recordings remain exclusive.** Ordinary placement steps stay preserved in the setup but do not execute while the route uses a manual recording. Unused placement keys are no longer required for that path.
