# Expeditions Macro v1.3.0-beta.40

This silent prerelease keeps dense Placement Setup coordinates readable by automatically separating their labels. It does not send a Discord release announcement.

## Highlights

- Placement-map labels now size for their unit and phase text instead of using one fixed label width.
- Nearby labels automatically fan into deterministic, collision-free horizontal lanes while their saved placement coordinates remain unchanged.
- Marker labels avoid other placement points, remain inside the canonical 808 by 611 map, and extend their connector lines to the adjusted position.

## Validation

- 1,251 application and detector tests passed.
- 5 Deep Debug Viewer tests passed.
- All 74 dark/light UI snapshot states rendered successfully and the dense marker layout was inspected in both themes.
- Locked restore, zero-warning Release build, formatting, repository policy, and diff hygiene passed.
