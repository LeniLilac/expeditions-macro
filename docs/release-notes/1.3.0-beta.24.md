# Expeditions Macro v1.3.0-beta.24

This silent beta adds the Villain Invasion Event workflow, updates Expedition and startup navigation for the current game interface, and expands deterministic Debug input testing. It does not send a Discord release announcement.

## Event workflow

- Fast no-align Placement Setup and Macro plans support Villain Invasion Acts 1 through 3.
- Event navigation starts from a verified Lobby, selects the Event and Act, enters prestart, performs each Act's deterministic first-load movement, and preserves that preparation across Repeat Stage runs.
- Event Victory is recognized with or without the optional Next Stage button. The macro continues to choose Repeat Stage for repeats rather than advancing.
- Event matches use the existing recoverable 12-minute impossibility watchdog.

## Current game interface

- Expedition map, difficulty, and Select Stage detection support the current Play interface.
- Startup opens Settings through paced accessibility navigation, adjusts UI scale before Lobby verification, and disables Event Theme with the other required settings.
- Event-themed Lobby frames no longer impersonate Settings, while valid themed Lobby recovery remains supported.
- Returning to Lobby through accessibility navigation verifies the confirmation transition before startup resumes.

## Debug tools

- A held-key utility can arm a supported key and duration, then execute it through F6 with ordered Deep Debug input records.

- All 719 fast application, Windows-input, workflow, startup, Event, and settings tests pass.

- All 5 Deep Debug Viewer tests pass.
