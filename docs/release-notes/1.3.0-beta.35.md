# Expeditions Macro v1.3.0-beta.35

This silent prerelease makes manual recording and ordinary placement playback more reliable, clarifies their authoring modes, and fixes a field-observed Villain Invasion Event Home variant. It does not send a Discord release announcement.

## Highlights

- Placement Setup now shows **Recording Mode** and **Step Mode** in the route header when advanced recordings are enabled. The selector stacks cleanly at narrow widths, autosaves its assignment, and preserves every ordinary placement step when the route switches modes.
- The advanced-recording toggle now lives under **Settings > Experimental**. Settings Diagnostics separately explains that key bindings are read-only there and directs users to Dashboard > Controls.
- Manual recording capture now orders mixed keyboard and mouse callbacks by the native Windows timeline. It saves an explicit pointer anchor for a valid one-pixel action difference and rejects larger incomplete paths before saving.
- Manual playback retains absolute-timeline scheduling and accepts an inclusive total offset from -50 through +50 milliseconds for each event while preserving pre-send, post-send, pointer, focus, geometry, and held-input safeguards.
- Expedition Placement Setup now allows each unit slot once across both phases, and every setup rejects new points inside the fixed central hotbar/HUD region. Existing invalid rows remain available for editing and are skipped individually during playback instead of being silently removed.
- Ordinary placement first tries one immediate place/select pair, parks the pointer before selected-unit proof, then uses at most three bounded slow place/select pairs. Unit-key normalization still runs only once and the complete attempt remains capped at eight coordinate clicks. A row that still lacks proof is logged and skipped without targeting, Auto Upgrade, successful-placement progress, or private-server recovery; the next configured step continues.
- Step Mode now requires a matching **Quick Placement key** under Dashboard > Controls. After normalization, the macro briefly holds it and confirms the stable cyan Quick Placement title before clicking a map coordinate. It retries selection once, then skips only that row if the unit still is not selected. Recording Mode does not require this key.
- Compact Placement Setup now passes wheel input from the nested placement list to the outer workspace at the inner list's top and bottom boundaries, keeping lower controls reachable.
- Villain Invasion Event Home now recognizes the field-observed one-pixel lower border on the live Event Gamemode button without weakening selected-tab, label, action, carousel, or Act-selector ownership.
