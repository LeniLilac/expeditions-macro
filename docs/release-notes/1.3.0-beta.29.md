# Expeditions Macro v1.3.0-beta.29

This beta adds Macro-plan loops, verified unit targeting, a safer fresh-session startup, and substantially less detector work in live matches. It is prepared as a source commit only unless a later release is explicitly requested.

## Highlights

- Macro plans can repeat one contiguous task range for a chosen number of runs or forever. Lifetime victories, defeats, and runtime remain cumulative across every loop.
- Fast no-align Placement Setup has 50–200% visual zoom, direct mouse-wheel zoom, middle-button drag panning, a wider step rail, and a targeting priority on each placement.
- Placement playback proves the unit-selection panel appeared before applying targeting. It normalizes the slot once with select, Cancel, and a select/deselect/reselect sequence, then retries only a 200-millisecond approach from 50 client pixels away and one click at that coordinate.
- Settings adds the required Change Unit Targeting, Upgrade Unit, and Toggle Auto Upgrade Unit bindings, with names matching Anime Expeditions.
- **Restart Roblox at Macro start** is enabled by default and establishes one verified private-server Lobby before the plan begins.
- Challenge-to-Event handoff now backs through every retained Play layer before attempting Lobby navigation.
- Live-match detection skips unrelated states, shares exact work per captured frame, and avoids Deep Debug stack-trace overhead while logging is disabled.
- The Debug workspace includes a benchmark for capture, mode detection, root recovery, total work, and estimated production polling rate.
