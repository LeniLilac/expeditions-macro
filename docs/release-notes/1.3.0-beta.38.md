# Expeditions Macro v1.3.0-beta.38

This silent prerelease makes Step Mode placement substantially faster and prevents manual-recording timing misses from needlessly restarting Roblox. It does not send a Discord release announcement.

## Highlights

- Step Mode now places a complete Before Start phase or equal-due After Start batch while holding Quick Placement: Cancel Placement, select only when the consecutive unit changes, and send three direct clicks per coordinate over 50 milliseconds.
- Targeting, Auto Upgrade, and panel dismissal run afterward in a separate verified pass, so every confirmed row is configured once in author order.
- Placement Setups can use one through eight total attempts. The default performs one fast batch and skips only an unconfirmed row; additional attempts retry only that failed row.
- Manual recording playback now uses a dedicated timing worker and direct Win32 target probes while preserving the inclusive +/- 50-millisecond safety bound.
- A manual-playback timing miss reports its exact signed drift and stops locally instead of being mistaken for a Roblox session timeout and consuming process recovery.
- Automatic recovery now permits ten Roblox restarts in ten minutes and blocks the eleventh.
