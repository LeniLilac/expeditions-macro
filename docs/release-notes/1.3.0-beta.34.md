# Expeditions Macro v1.3.0-beta.34

This silent prerelease fixes unreachable Placement Setup controls at compact and medium window sizes. It does not send a Discord release announcement.

## Highlights

- Placement-step lists now scroll by pixels instead of whole rows. Auto Upgrade priority and After Start delay remain reachable even when one expanded step is taller than its viewport.
- Mouse-wheel scrolling, scrollbar dragging, keyboard navigation, and focus-driven scrolling all retain access to the complete selected step.
- The existing Placement Setup layout, autosave behavior, placement ordering, and action controls remain unchanged.

## Validation

- The Release solution builds with zero warnings and repository policy passes.
- All 1,181 application and detector tests and all 5 Deep Debug Viewer tests pass.
- All 68 dark/light UI snapshots render, including structural reachability checks at 960 by 640 and 1400 by 1080.
- The portable package and installed application must pass their release verification gates before publication.
