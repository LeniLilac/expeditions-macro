# Expeditions Macro v1.3.0-beta.59

This beta fixes Macro Plan scheduling after Bounty runs out of reroll Gold. It is published as a silent prerelease and does not send a Discord release announcement.

## Highlights

- Treats a Bounty that is excluded for the current scheduler run as settled when traversing loop scopes.
- Applies the same session exclusion to task selection and wake-time calculation.
- Allows eligible Event and Expedition tasks in a trailing Forever loop to continue instead of idling until the next recurring Challenge or Utility task.

## Safety boundaries

- Only tasks explicitly excluded for the current scheduler run are skipped; recurring cooldown, daily-limit, and finite-loop completion rules are unchanged.
- The scheduler does not synthesize eligibility or progress for excluded tasks.
- Bounty progress remains persisted, and a later scheduler run can retry Bounty under its existing restart semantics.

## Validation

- Added an exact Bounty-no-Gold regression proving that a trailing Forever loop continues to its eligible task.
- Passed 1,636 non-golden application tests and 120 golden-image and cross-state detector tests.
- Passed 6 Deep Debug Viewer tests and 15 Detector Viewer tests.
- Passed locked restore, zero-warning Release build, repository policy, diff hygiene, packaging, checksum verification, and packaged-app smoke checks.
