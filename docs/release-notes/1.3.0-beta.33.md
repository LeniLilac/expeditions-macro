# Expeditions Macro v1.3.0-beta.33

This silent prerelease makes Fast Placement Setup the only supported camera-preparation workflow and hardens UI navigation for slower devices and delayed game rendering. It does not send a Discord release announcement.

## Highlights

- **Placement Setup is now Fast-only.** Camera Models, learned yaw alignment, and their editing surfaces are removed. Plans and presets saved by earlier public betas remain readable, but legacy camera-model tasks stop before Roblox input with guidance to replace them with a current Fast Placement Setup.
- **Slow UI waits use fresh observations.** Navigation, recovery, setup, match-start, and terminal handoff can finish their required confirmations even when capture or recognition is slow. Every workflow keeps its existing hard deadline and bounded input-attempt cap, and a static fallback coordinate can never authorize a click.
- **Settings handles the brighter gear variant.** Startup preparation recognizes the field-observed high-contrast Settings gear at the supported top-bar positions without treating selected or unrelated controls as Settings.
- **Event navigation tolerates delayed and shifted rendering.** The shifted Act selector is recognized before retained home evidence, Event content receives an observation-aware wait, and Villain Invasion home can be proven before its decorative header finishes rendering by requiring both the selected Villain Invasion tab and the live Event Gamemode action.
- **Recording playback tolerates real pointer rounding.** A one-pixel client-coordinate variance after acknowledged motion no longer causes a false playback stop. Focus ownership, exact event timing, button-state cleanup, and drift limits remain enforced.
- **Story shows Hard mode only where the game supports it.** Act routes retain the option; Mastery and Infinite routes hide it and clear stale Hard-mode state.
- **Existing authoring and pinning behavior remains intact.** Macro Plan and Placement Setup changes still autosave, placement phases and Auto Upgrade priorities remain editable, manual recordings remain exclusive of stored ordinary steps, and pinned Roblox keeps the established coverage-aware suspend/minimize behavior.

## Validation

- All 1,181 application and detector tests and all 5 Deep Debug Viewer tests passed.
- All 66 dark/light UI snapshots rendered and were visually inspected.
- The Release solution, repository policy, detector corpus, dark/light UI snapshots, portable package, and installer must pass their release gates before publication.
