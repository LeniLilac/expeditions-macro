# Expeditions Macro v1.3.0-beta.23

This silent beta repairs damaged detector-pack installations automatically and simplifies the Fast no-align sharing label. It does not send a Discord release announcement.

## Detector-pack startup repair

- Every installed detector pack is validated against its own manifest before its version is trusted.
- A damaged installed pack is atomically replaced with the known-good bundled copy, even when the damaged manifest claims a newer version.
- Healthy newer detector packs remain installed.
- If the application bundle itself is incomplete, startup now gives clean extraction and reinstall guidance instead of only naming the first missing image.

## Interface

- The Fast no-align import/export panel is now named **Share config**.

## Validation

- All 771 application, detector, Windows-input, workflow, sharing, startup-preflight, and upgrade tests pass.
- All 5 Deep Debug Viewer tests pass.
- All 28 dark/light UI snapshots render successfully.
- Repository policy, release metadata, a warning-free Release build, checksums, native dependencies, portable startup, and isolated installer startup/uninstall pass.
