# Expeditions Macro v1.3.0-beta.43

This silent prerelease adds setup-level placement defaults and fixes slow Expedition recovery transitions. It does not send a Discord release announcement.

## Highlights

- Match settings now expose default Targeting and Auto Upgrade priorities at the top of the Step Mode form.
- New map placements and newly added Place actions inherit those setup defaults.
- Applying new defaults never rewrites existing Match Steps.
- Older setup files remain compatible and use Target First plus Auto Priority 1 when the new fields are absent.
- Expedition recovery now waits through slow, unclassified teleport/loading frames after a verified action, while retaining the existing hard deadline and input-attempt limits.
- A delayed prestart screen is accepted as the completed transition instead of causing the stale map-preview Start action to be replayed.
