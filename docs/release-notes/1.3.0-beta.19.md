# Expeditions Macro v1.3.0-beta.19

This silent beta restores a safe portable-ZIP folder boundary and updates the experimental Debug refuel defaults from manual route tuning. It does not send a Discord release announcement.

## Portable ZIP

- The portable archive contains one top-level `ExpeditionsMacro` folder.
- `ExpeditionsMacro.exe` is directly inside that folder.
- No application or self-contained runtime files are left loose at the archive root, preventing extraction tools from scattering them into an unrelated directory.

## Debug refuel defaults

- Gold Mine now defaults to `W 3000 ms`, `A 820 ms`, and `W 2600 ms`.
- Resource Drill now defaults to `W 3000 ms`, `A 750 ms`, `W 1000 ms`, and `A 1600 ms`.
- Existing saved Debug settings remain user-controlled.

## Validation

- All 658 application and detector tests and all 5 Deep Debug Viewer tests pass.
- All 26 dark/light UI snapshots render from the extracted portable application and the isolated installer.
- Repository policy, release metadata, a warning-free Release build, checksums, native dependencies, portable extraction layout, packaged startup, and installer startup/uninstall pass.
