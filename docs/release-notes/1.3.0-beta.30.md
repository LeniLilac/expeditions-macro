# Expeditions Macro v1.3.0-beta.30

This silent prerelease introduces a dedicated Dashboard, an interactive pinned Roblox window, Scratch-style nested Macro-plan loops, faster equivalent state detection, and stronger placement cleanup. It does not send a Discord release announcement.

## Highlights

- **Dashboard and Macro Plan are separate workspaces.** The Dashboard keeps the live Roblox view, run controls, current status, logs, Discord reporting, private-server recovery, startup preparation, and keybindings together. Macro Plan is reserved for building and sharing the task sequence.
- **Pinned Roblox remains directly usable.** Pinning places the real Roblox top-level window over the Dashboard instead of showing a passive mirror. Users can click and control Roblox normally, and the app restores its original window state when unpinned, navigating away, minimizing, or closing.
- **Loops work like nested blocks.** Users add Loop blocks and drag tasks or other finite loops into them. Plans can contain multiple finite loops, nest to three levels, and optionally end in one root-level Forever loop. Empty or structurally invalid loops are rejected before saving.
- **Existing plans remain usable.** Task-only plans and the earlier contiguous-loop format migrate into the block structure, and Fast no-align share codes preserve nested loops without including progress or secrets.
- **Detection work is lower and measurable.** Mode-owned state subsets, per-frame evidence reuse, and action-button caching reduce unnecessary comparisons while an expanded Debug benchmark reports production-path latency. Equivalence tests ensure optimized paths choose the same state as full detection.
- **Placement finishes cleanly.** After the final placement, the macro verifies that the selected-unit panel has closed through bounded idle-area clicks, then parks the cursor at its idle corner.
