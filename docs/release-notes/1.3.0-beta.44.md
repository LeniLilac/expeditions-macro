# Expeditions Macro v1.3.0-beta.44

This silent prerelease fixes saved-team preparation when Unit Inventory remains open. It does not send a Discord release announcement.

## Highlights

- Saved-team preparation now distinguishes the visible Unit Inventory from the Unit Teams list before advancing.
- The macro clicks the live detected Teams action instead of relying on a stale fixed coordinate.
- The Teams destination must expose its stable detector-owned scrollbar before team loading begins.
- If the verified Unit Inventory remains open, the macro retries the live Teams action once and then stops with a recoverable error.
- Slow opening transitions remain observation-aware without increasing the two-click input cap.
