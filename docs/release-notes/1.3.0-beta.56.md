# Expeditions Macro v1.3.0-beta.56

This beta fixes Infinite Bounty wave monitoring on bright maps whose scenery shows through the translucent Roblox status pill. It is published as a silent prerelease and does not send a Discord release announcement.

## Highlights

- Evaluates the Wave pill against its immediate bounded background instead of assuming the complete rail is always darker than one fixed luminance.
- Recognizes the supplied bright-scene no-voice layout at the supported `(421,28)` counter origin.
- Retains the legacy `(389,48)`, ordinary no-voice `(421,28)`, and compact `(386,28)` layouts.
- Exposes the rail and local-background geometry to Detector Viewer for direct inspection.

## Safety boundaries

- The blue Wave badge, neutral Wave label, and both bounded pill rails must still agree at exactly one reviewed layout.
- A bright region with no local pill contrast remains unknown.
- Number-template output never owns the counter by itself.
- Bounty exit progress still additionally requires the independent gameplay hotbar, Unit Manager, and Stage Info controls.
- Ambiguous layouts and transient or ambiguous digits send no input and do not advance wave-exit evidence.

## Validation

- Replayed all 46 gameplay observations from the supplied beta.55 archive. Counter ownership improved from 0/46 to 46/46; 44/46 frames also yielded an exact number, while two ambiguous/transient frames remained safely unknown.
- Added a privacy-reviewed canonical bright-scene fixture, an adaptive translucent-pill positive, and a no-pill-contrast negative.
- Passed 1,597 non-golden application tests and 120 golden-image and cross-state detector tests.
- Passed 6 Deep Debug Viewer tests, 15 Detector Viewer tests, and all 90 dark/light main-app UI states.
- Passed locked restore, zero-warning Release build, repository policy, formatting, diff hygiene, packaging, and privacy checks.
