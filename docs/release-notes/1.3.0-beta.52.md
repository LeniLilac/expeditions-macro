# Expeditions Macro v1.3.0-beta.52

This beta hardens Sell Unit Match Steps when Roblox visibly ignores an otherwise complete configured-key input. It is published as a silent prerelease and does not send a Discord release announcement.

## Highlights

- A normal Sell Unit action still sends the configured key exactly once.
- Roblox now has one second to close the selected-unit panel before the action is considered ignored.
- If the same panel remains freshly verified, the macro retries no more than twice instead of immediately restarting Roblox.
- A sale retires its placement identity only after stable panel closure.

## Safety boundaries

- Every retry requires fresh selected-unit-panel ownership; unknown or lost panel evidence sends no additional Sell input.
- The complete transaction is capped at three configured-key presses.
- Cancellation stops before another retry.
- Three ignored verified attempts retain the typed recoverable UI failure and configured Roblox recovery behavior.
