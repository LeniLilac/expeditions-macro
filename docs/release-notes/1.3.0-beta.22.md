# Expeditions Macro v1.3.0-beta.22

This silent beta simplifies Fast no-align placement authoring, separates new and legacy plans, and hardens automated UI validation. It does not send a Discord release announcement.

## Placement Setup

- The bottom authoring rail now contains only Team, placement phase, and unit slot.
- New placements retain the fixed 900 ms placement interval used by Fast no align.
- New After Start placements default to 30 seconds.
- Each After Start step keeps its own editable delay in the Placement steps list.
- Existing saved step intervals and After Start delays are preserved.

## Workflow separation

- A beta.20 settings file enables Fast no align when first opened by the new workflow.
- Fast no-align mode hides legacy preset pages, camera models, legacy placement models, and legacy macro plans.
- Disabling Fast no align restores those preserved legacy files without converting or deleting them.
- Fast no-align plans and legacy plans no longer appear together in the plan selector.

## Interface and validation

- Mode-specific Macro options align directly beneath the task fields without the empty “Mode options” rail.
- Off-screen UI rendering writes page-level progress and exits on startup or dispatcher errors without opening an invisible modal.
- The renderer has a bounded three-minute process timeout with actionable failure output.

## Validation

- All 769 application, detector, Windows-input, workflow, sharing, startup-preflight, and upgrade tests pass.
- All 5 Deep Debug Viewer tests pass.
- All 28 dark/light UI snapshots render successfully, including Macro Plan and Placement Setup.
- Repository policy, release metadata, a warning-free Release build, checksums, native dependencies, portable startup, and isolated installer startup/uninstall pass.
