# Expeditions Macro v1.3.0-beta.31

This silent prerelease adds advanced manual input recordings, a cleaner Macro Plan editor, safer startup detection, and a more compact Dashboard. It does not send a Discord release announcement.

## Highlights

- **Manual recordings provide an exact-input route option.** Advanced users can record keyboard, mouse movement, clicks, and wheel input from prestart through gameplay, then assign that recording to a Placement Setup. Recording and test playback are armed with the global macro hotkey, and playback stops safely if timing drifts by more than 10 milliseconds.
- **Share codes restore complete ordinary plan dependencies.** Referenced Fast no-align presets and their full Placement Setup data travel with the plan, while manual recordings remain device-local and block export until their setup assignment is disabled.
- **Macro Plan authoring is popup-based and easier to reorder.** Tasks can be inserted directly into a selected loop, Challenge types use multi-select tiles, loop settings live behind one settings action, and a single insertion line shows the exact sibling boundary during drag and drop.
- **Placement Setup has clearer route modes.** Manual routes show only Team and Recording controls. Ordinary routes expose per-unit Auto Upgrade choices, and every placed unit's selection panel is closed before the next placement begins.
- **The Dashboard uses its space more effectively.** The Roblox window stays left-aligned, the bounded Run log fills the lower Current run area, and narrow windows stack Current run between Roblox and Discord without horizontal page scrolling. Maximizing respects the taskbar, pinned Roblox suspends whenever another app or a macro dialog needs the foreground, and automatic unpinning caused by navigation, scrolling, or minimizing the utility now minimizes Roblox. Manual unpin and application shutdown still restore Roblox normally.
- **Control setup guidance follows the current interface.** Missing, invalid, or conflicting key messages direct users to scroll down to Controls on the Dashboard and keep each required game binding matched to Anime Expeditions.
- **Startup and navigation are more tolerant without becoming blind.** UI Scale and required game-settings preparation have independent switches. UI Scale navigation uses visual Misc-page anchors and direct Settings-panel measurement with an inclusive two-percent acceptance range; disabling it skips scale measurement entirely. Slow devices receive observation-count budgets, and Expedition map selection tolerates the reported vertical lighting shift.
- **Saved Team loading covers the complete field layout.** Team 4's confirmation dialog now recognizes its valid two-row background while retaining the strict dimmed-panel and live-confirm-action checks used for every Team.
- **Event navigation no longer assumes an account default.** If Events opens on Beginner's Path or another catalog selection, the macro verifies and selects Villain Invasion before continuing to its act selector.
- **Safety defaults migrate once.** The first beta.31 load of older settings enables startup private-server restart, failed-recovery private-server restart, startup UI Scale correction, and required game-settings correction. Persisted settings schema v3 prevents subsequent loads from overriding the user's choices; a schema v2 combined preparation choice seeds both new switches.
- **Release contents are simpler.** Detector data is bundled and hash-verified inside the app, with no detector updater or separate detector archive. The portable ZIP exposes `ExpeditionsMacro.exe` at its root and keeps dependencies in the adjacent `ExpeditionsMacro` directory.
