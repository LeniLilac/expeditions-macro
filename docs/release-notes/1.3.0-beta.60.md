# Expeditions Macro v1.3.0-beta.60

This beta fixes Macro Plan handoff when Challenge daily-limit evidence was saved before the current run. It is published as a silent prerelease and does not send a Discord release announcement.

## Highlights

- Returns a scheduled Challenge task to the scheduler immediately when its persisted daily-limit deadline is still active.
- Closes the live Challenge selector through the existing verified handoff before another workflow receives navigation ownership.
- Allows eligible Bounty, Utility, Event, and Expedition tasks to continue instead of waiting inside Challenge until midnight UTC.

## Safety boundaries

- The selector close still requires fresh Challenge ownership and a verified shared game-mode selector before control is returned.
- Standalone Challenge runs retain their existing wait-until-reset behavior; only scheduled invocations that explicitly request unavailable-task handoff return early.
- The persisted deadline remains the task's next eligible time and still clears at `00:00 UTC`.

## Validation

- Reproduced the supplied beta.59 trace with an exact persisted-daily-limit runner regression; it failed in the midnight wait before the fix and now completes through the verified scheduler handoff.
