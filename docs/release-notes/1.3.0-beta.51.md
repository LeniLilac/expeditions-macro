# Expeditions Macro v1.3.0-beta.51

This beta hardens Mythic Bounty number recognition against field-observed glyph rasterization and prevents Villain Invasion Event Home from being mistaken for Act Selection under Roblox's performance overlay. It is published as a silent prerelease and does not send a Discord release announcement.

## Highlights

- Mythic Bounty `#1` through `#10` recognition keeps the exact embedded-template path first, then uses a bounded in-process glyph comparison only inside the live card action's reviewed title window.
- Field-observed `#4`, `#5`, and `#6` raster variants now reconcile correctly after the macro cancels Mythic reroll confirmation.
- Villain Invasion Event Home remains Event Home when Roblox's performance overlay adds red and white pixels across the page; Act Selection now requires its compact heading/subtitle structure together with the existing selector rail.
- New Bounty tasks start at zero parked non-viable Bounties. The redundant visible label is removed while the Gold/time endpoints and accessible control name remain.

## Safety boundaries

- Exact Mythic suffix templates remain authoritative when they match.
- The glyph fallback requires a similarity floor, a clear runner-up margin, and the reviewed title position. Ambiguous evidence remains unknown.
- A recognized suffix cannot own a Bounty card or authorize input; the live yellow Reroll or green Claim action remains mandatory.
- Act Selection still requires independent full-width selector-rail ownership. Mutable page artwork and performance-overlay pixels cannot own the state.
- Existing Bounty tasks retain any explicitly saved parking value; only newly authored tasks default to zero.
