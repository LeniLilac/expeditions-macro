# Expeditions Macro v1.3.0-beta.26

This silent prerelease fixes Event scheduler handoffs and hardens unit placement selection. It does not send a Discord release announcement.

## Highlights

- Event-to-Event and normal-mode-to-Event transitions now return through a verified Lobby instead of searching Play for an unavailable Event route.
- Event-to-normal transitions now verify the post-match party panel, select **Change Gamemode**, and hand off at shared navigation.
- Placement playback now resets an uncertain selected-unit state before every attempt, reselects the intended slot, then preserves the existing target jitter and 200 ms settle.
- Settings > Controls now includes a configurable **Placement cancel key**, defaulting to `Z`.

## Validation

- 49 focused scheduler, placement, settings-model, and persistence regressions passed.
- 831 application and complete cross-state detector tests passed with zero skips.
- 5 Deep Debug Viewer tests passed.
- The Release solution built with zero warnings and repository policy passed.
- All 28 dark/light UI snapshots rendered successfully.
