# Expeditions Macro v1.3.0-beta.39

This silent prerelease lets manual recording playback tolerate ordinary Windows scheduling jitter without shifting the recording timeline. It does not send a Discord release announcement.

## Highlights

- Manual playback keeps +/- 50 milliseconds as its timing-quality target but continues on the recording's original absolute event offsets while drift remains below +/- 2,000 milliseconds.
- Drift never delays later events relative to an earlier late input, so playback can catch up naturally.
- Reaching the +/- 2,000-millisecond hard stop still releases every held key and mouse button, reports the exact event boundary and signed drift, and stops locally without restarting Roblox.
