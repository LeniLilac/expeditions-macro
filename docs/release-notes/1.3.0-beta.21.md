# Expeditions Macro v1.3.0-beta.21

This silent beta introduces the default Fast no-align workflow, a map-based Placement Setup editor, portable text sharing, device-feedback UI-scale calibration, and a required-game-settings preflight. It does not send a Discord release announcement.

## Fast no-align Placement Setup

- Fast no align is enabled by default and prepares maximum zoom plus a straight-down pitch without changing deterministic map yaw.
- Placement Setup displays native 808 by 611 map captures and stores each point's unit slot, Before Start or After Start phase, interval, and independent After Start delay.
- Team selection belongs to each Placement Setup. Repeated matches reuse the prepared camera and Team until Lobby, recovery, or a new Roblox process invalidates that state.
- Expedition routes can share one category setup, each Story map can share one setup across Acts, Infinite, Mastery, and Challenge, and exact route setups override their category. Raid acts remain exact-only.
- Camera-model presets and their editors remain available after Fast no align is disabled.

## Plans and portable sharing

- Macro Plan owns Challenge types, defeat retries, Story Hard mode, Expedition difficulty, checkpoint extraction, boss targets, completion targets, and task priority.
- Export creates a compact `EMFAST1:` Base64 text code containing the plan and only the Placement Setups it resolves.
- Import validates the bundle before replacing matching local plan/setup IDs.
- Share codes exclude camera models, run history, application settings, webhooks, Discord IDs, private-server links, diagnostics, logs, and Windows profile data.

## Startup calibration and recovery

- Automatic startup checks normalize rendered Roblox UI scale before requiring Lobby, then apply the documented Gameplay, Graphics, Units, and Misc settings profile.
- UI scale uses measured visual feedback, so a device whose numeric `1.00` renders like the reference `1.10` is corrected toward `0.91` rather than being assumed canonical.
- Standalone UI Scale and Settings runs are available in Debug.
- Saved-team alignment continues toward the requested stable Load Team action instead of stopping after a fixed number of drags.
- Recoverable Roblox UI/session failures save configured diagnostics, restart through the protected private-server link, and retry the same incomplete task without recording progress.

- All 766 application, detector, Windows-input, workflow, sharing, and startup-preflight tests and all 5 Deep Debug Viewer tests pass.
- All dark/light UI snapshots render successfully, including Macro Plan, Placement Setup, Settings, and Debug.
