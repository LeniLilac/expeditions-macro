# Expeditions Macro v1.3.0-beta.42

This silent prerelease fixes the scheduled resource-refuel return path. It does not send a Discord release announcement.

## Highlights

- Scheduled Gold Mine and Resource Drill Utilities no longer press the open-only Play key after refueling.
- Refuel completion now enters Areas directly from the owned station state, selects the verified Lobby category and Spawn card, and proves Lobby before scheduler ownership resumes.
- If a Utility inherits an already-open Play surface from the previous task, it closes each verified Play layer through the shared detector-owned Back action before starting the Areas route.
- Regression automation now models the real open-only Play key and refuses to let Areas replace an open Play interface, preventing the beta.41 failure path from returning.
