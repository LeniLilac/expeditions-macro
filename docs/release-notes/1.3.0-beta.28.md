# Expeditions Macro v1.3.0-beta.28

This silent prerelease adds Villain Invasion Act 4, hardens placement and Lobby recovery, expands Deep Debug evidence, and prevents automation on unsupported Windows display scaling. It does not send a Discord release announcement.

## Highlights

- Villain Invasion Act 4 is available in Fast no-align Placement Setup and Macro plans, including emblem-guided navigation, its retained placement view, final Victory handling, and a recoverable 17-minute runtime guard.
- Roblox must be on a monitor using 100% Windows display scale. The app reports the detected percentage before sending automation input when the scale is unsupported.
- Placement playback keeps the pointer on one target for the complete unit-selection sequence, makes three bounded placement attempts, then parks the cursor before the next unit.
- Placement steps support phase-safe drag reordering, and the new timing panel stores the interval between placements plus the setup's default After Start delay.
- Deep Debug records action-boundary frames around every high-level Roblox input and window action, making sparse detector polling periods reconstructable.
- Lobby return opens the confirmation through accessibility navigation, clicks the verified red confirmation action directly, and requires a stable Lobby before continuing.
- Prestart detection in Challenge, Story, Raid, and Event is no longer suppressed by Expedition-only reward-card evidence.
