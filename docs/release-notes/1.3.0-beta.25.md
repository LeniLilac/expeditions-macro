# Expeditions Macro v1.3.0-beta.25

This silent beta hardens the current Event-update Settings layout, makes placement clicks more reliable, and adds focused Debug and Placement Setup controls. It does not send a Discord release announcement.

## Highlights

- Startup settings normalization recognizes both supported Miscellaneous page row positions without blind clicks or relaxed toggle checks.
- Placement playback performs two acknowledged one-pixel cursor passes over each target, settles for 200 milliseconds, and then uses the existing jittered placement click.
- Debug can run the production **Teleport to lobby** navigation path with Deep Debug coverage.
- Placement Setup accepts number-row and numpad keys `1` through `6` to select unit slots while leaving text-field input unaffected.
- The new Debug lobby action uses a locally registered Lucide icon, preventing the reported WPF startup resource failure.

## Validation

- All 824 application, Windows-input, workflow, startup, placement, and detector tests pass.
- All 5 Deep Debug Viewer tests pass.
- All 28 dark/light UI snapshots render from both current source and the packaged application.
- Repository policy, release metadata, formatting verification, a warning-free Release build, the complete detector corpus, checksums, native dependencies, and packaged startup pass.
