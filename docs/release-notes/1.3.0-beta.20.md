# Expeditions Macro v1.3.0-beta.20

This silent beta hardens private-server recovery and long-running match supervision, fixes cross-mode reward detection, dismisses rare Spirit City unit-drop presentations safely, and adds a fast camera-preparation utility for Debug testing. It does not send a Discord release announcement.

## Stable private-server recovery

- A relaunched Roblox client is standardized to 808 by 611 before recovery continues.
- The scheduler resumes only after three consecutive Lobby detections from the new Roblox process.
- Loading, teleport, selector, prestart, result, AFK, capture-error, and unknown frames reset Lobby stability and cannot consume Play-key attempts or route clicks.

## Match recovery and mode ownership

- Challenge, Story Act/Mastery, and Raid runs recover after exceeding the twelve-minute impossible-duration threshold; Story Infinite remains unbounded.
- Checkpoint-targeted Expeditions use a ten-minute zero-boss threshold or fifteen minutes per positive boss target. Extraction-disabled runs remain unbounded.
- A watchdog timeout saves configured failure diagnostics, restarts through the configured private server, and retries the same incomplete task without recording match or task progress.
- Expedition reward cards now require their live dark **Select Upgrade** rails and are never classified by Challenge, Story, or Raid.

## Raid and Debug tools

- Spirit City Raid Acts 2 and 3 dismiss rare unit-drop presentations from a safe client corner after all configured after-start placement work has completed.
- The Debug **Fast no align** action zooms fully out, temporarily enables Shift Lock, and clamps the camera pitch straight down without changing yaw.

## Validation

- All 692 application and detector tests and all 5 Deep Debug Viewer tests pass.
- All 28 dark/light UI snapshots render from source, the extracted portable application, and the isolated installer.
- Repository policy, release metadata, a warning-free Release build, checksums, native dependencies, portable extraction layout, packaged startup, and installer startup/uninstall pass.
