# Expeditions Macro v1.3.0-beta.18

This silent beta adds experimental resource-refuel testing tools and fixes current Victory, card-reward, and legacy camera-model failures. It does not send a Discord release announcement.

## Experimental refuel tools

- The Debug workspace can test Gold Mine, Resource Drill, or both from the current lobby.
- A second start mode relaunches Roblox through the configured private-server link and waits for the lobby.
- Settings now includes an Areas menu key used by these Debug tools.
- Gold Mine and Resource Drill movement timings, retry count, and target station are configurable for dataset collection and route tuning.
- The route uses blind movement only after the verified Expeditions Hub teleport, then resumes visual verification at each station UI.
- This is a Debug-only testing surface. It is not scheduled by Macro plans and does not yet provide automatic eight-hour refueling.

## Detection fixes

- Challenge Victory detection now remains stable while the cyan result artwork animates by requiring the Victory-only Close, View Party, and repeated roster-reward structures.
- Expedition card rewards now recognize the current brighter cyan progress header while continuing to require the three independent card actions.
- The reported bright reward chooser is selected by the macro instead of being left for Roblox's automatic timeout.

## Camera model compatibility

- Loading obsolete schema 1 or 2 camera models now explains that the affected preset must select a current model and be saved.
- Expedition presets show an immediate warning when their saved camera-model reference is missing.
- Rebuilding a Macro plan alone is correctly identified as insufficient because the model reference belongs to the preset.

## Validation

- All 658 application and detector tests pass, including the complete cross-state corpus and the new refuel, Victory, reward, and camera compatibility regressions.
- All 5 Deep Debug Viewer tests pass.
- All 26 dark/light UI snapshots render successfully.
- Repository policy, diff checks, a locked restore, and a warning-free Release build pass.
