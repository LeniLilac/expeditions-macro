# Expeditions Macro v1.3.0-beta.47

This beta makes the live Bounty Board authoritative when a user starts a new Macro operation. It is published as a silent prerelease and does not send a Discord release announcement.

## Highlights

- Opens and processes the Bounty Board before any saved Bounty objective can launch on a new Macro start.
- Claims completed Bounties during that initial transaction.
- Reconciles active Mythic numbers when the user changed the board while the Macro was stopped.
- Applies the configured reroll and parking policy before selecting the next deterministic objective.
- Retries an initial reconciliation interrupted by process recovery, while preserving active-work-first behavior after the reconciled state is saved.

## Safety boundaries

- Saved Bounty state cannot authorize route input until the live board transaction succeeds.
- Claims, rerolls, and number recognition retain their existing fresh state-owned evidence and bounded retry requirements.
- A failed board transaction does not mark the operation reconciled or silently trust stale local progress.
