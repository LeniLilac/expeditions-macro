# Resource-refuel fixtures

the Areas, Gold Mine, and Resource Drill detectors.

The frames come from the passive 419-frame diagnostic capture supplied on
2026-07-24. The active player-name area was replaced with opaque black
rectangles before the images entered Git history. Those rectangles do not
intersect any detector or action region. No frame contains desktop chrome,
chat, notifications, webhook data, private-server links, or other secrets.

- `AreasMenu_01.png`: Areas opened on its default Upgrade section.
- `AreasExpeditions_01.png`: Expeditions selected with Expeditions Hub ready.
- `GoldMine_01.png`: Gold Mine station panel with Add Fuel available.
