the Areas, Gold Mine, and Resource Drill detectors.

supplied on 2026-07-24. The four fuel-state variants come from canonical
passive captures reviewed on 2026-07-29. The original active player-name area
was replaced with opaque black rectangles before those images entered Git
history. The later captures contain no visible account identity. No fixture
contains desktop chrome, chat, notifications, webhook data, private-server
