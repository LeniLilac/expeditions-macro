# Privacy

Expeditions Macro runs locally on Windows and has no analytics or telemetry.

It reads pixels from the selected Roblox window and sends simulated input only while a workflow is running. Detector and diagnostic frames target the Roblox window's own compositor surface, so another application covering Roblox is not included. HDR/Auto HDR pixels are converted locally to SDR before detection or PNG storage. Placement Setups, manual input recordings, compatible presets, settings, logs, application-managed detector references, and user-requested diagnostic screenshot ZIPs are stored under `%LocalAppData%\ExpeditionsMacro`. Retired legacy Camera Model JSON may remain there after an upgrade for compatibility, but the current app does not execute it.

Advanced manual recordings are disabled by default. When explicitly enabled and armed, low-level Windows hooks observe physical keyboard and mouse events only while Roblox is the foreground 808 by 611 client. Injected input and the macro hotkey are excluded. A saved recording contains replayable keys, client-relative pointer movement, clicks, wheel input, and exact timing, so it may contain sensitive activity the user performs during the recording. Raw recorded events remain excluded from Deep Debug archives. Delete unwanted recordings locally, and never record credentials, chat messages, private-server codes, or other sensitive text.

Manual diagnostic capture is started explicitly from Settings. Automatic failure capture is enabled by default and can be disabled there. While a macro runs, it keeps the latest 10 action-state screenshots in memory; after an unexpected error or a typed runtime/session failure that will trigger private-server recovery, it saves those frames and captures 10 more Roblox-client screenshots at 0.5-second intervals. Manual Stop does not trigger it. The app retains the 10 newest automatic error ZIPs and removes older automatic error ZIPs; manual diagnostic archives are not deleted by this cleanup. Diagnostic ZIPs contain captures of the Roblox client plus a local manifest with capture timing, action labels, and app version. Including the current macro run log is also enabled by default and can be disabled independently. The app does not upload these ZIPs. Review them before sharing because Roblox UI and logs can contain account names, chat, local paths, or other personal information.

Deep debug logging is disabled by default and requires an explicit warning confirmation. While enabled, macro, Placement Setup playback, manual recording, test playback, and diagnostic-capture operations record the Roblox frames requested by automation, detector state/score events, generated input, and workflow actions. They create a local ZIP after successful, canceled, and failed operations. Raw manual-recording events are not copied; playback contributes one metadata-only summary. The ZIP includes sanitized app settings, selected plans and compatible presets, the active detector pack, referenced Placement Setups, and a sanitized run log. Retired Camera Model and camera-shortcut payloads are not collected. Discord webhook values, Roblox private-server links, DPAPI-protected secret material, Discord user IDs, and the active Windows username/profile path are omitted from text entries. Deep debug frames can still contain any account names, chat, or other content visible inside Roblox. These potentially multi-gigabyte ZIPs remain in `diagnostics/` until the user deletes them and are never uploaded by the app.

Discord reporting is optional. When configured, the app sends only the event summary shown in the UI and a Roblox-window screenshot when a mode starts, when a Challenge match attempt starts, and for victory, defeat, or unexpected recovery. Result reports include both the current match runtime and cumulative macro runtime. Choosing **Test webhook** sends one Components V2 message without a screenshot or mention. Users may also enter a numeric Discord user ID; a terminal unexpected macro failure then sends five separate Components V2 messages that mention only that ID. A recoverable runtime/session failure creates local diagnostics and restarts without sending the misleading terminal “stopped unexpectedly” alerts. Manual Stop does not send these alerts. The webhook value is encrypted for the current Windows user with DPAPI and is never written to the application log. The Discord user ID is stored with the other local app settings.

Plan sharing is local and explicit. Export creates a compressed JSON bundle represented as a Base64 text code containing the selected Macro plan without progress, its referenced compatible Fast presets, and the complete ordinary Placement Setup dependencies those tasks resolve to, including coordinates, phases, delays, targeting, per-step Auto Upgrade, Team, route, default timing, and impossibility threshold. Manual input recordings remain device-local: raw recording events and recording references are excluded, and export stops when a resolved setup has **Use manual recording** enabled. Share codes also exclude retired Camera Models, app settings, webhooks, Discord IDs, private-server links, diagnostics, logs, and Windows profile data. Import validates the format and asks before replacing the same local plan, preset, or setup identities. The app does not upload or transmit share codes.

Roblox private-server restart stores one private-server link encrypted for the current Windows user with DPAPI. By default, each user-started Macro plan establishes a fresh private-server session before navigation; users may disable this behavior. When enabled, the app closes only a verified Roblox player process if one is open, passes a normalized `roblox://` private-server URI to Windows, and waits for the new client to reach Lobby. The same target can optionally recover bounded runtime failures. Roblox connects through the installed client and its existing signed-in account; the app does not receive or store Roblox credentials, cookies, or account tokens. The private-server link is never included in application logs, diagnostic manifests, or Deep Debug archives.
